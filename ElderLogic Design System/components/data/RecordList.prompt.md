Shows what the state has published about a home, as verbatim label/value rows in mono.

```jsx
<RecordList rows={[
  { label: 'License number', value: 'AL8271H' },
  { label: 'Last inspection', value: '2026-06-18' },
  { label: 'Enforcement actions on file', value: '0' },
]} />
<SourceNote>AZDHS licensing file · refreshed 1 Aug 2026</SourceNote>
```

Never add a star rating, a score, a rank or a red/amber/green pill to these rows. If a figure looks bad, it is still shown plainly — the state published it, ElderLogic did not judge it.
